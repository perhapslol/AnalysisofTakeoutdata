# 外卖数据集-多维度数据分析

此数据集包含了三个sheet：cpc、orders和shop，涵盖了丰富的外卖行业数据维度，非常适合用于外卖门店运营分析。本数据集源于网络，是学习powerbi过程中参考的b站up主提供的资料。

数据集详细介绍如下：

- cpc：包含广告点击成本相关数据，可用于分析广告投放效果。
- orders：包含订单数据，可用于分析门店订单量、销售额等指标。
- shop：包含门店信息，可用于分析门店经营状况、地域分布等。

通过本数据集，您可以进行以下维度的分析：

1. 门店经营状况：分析各门店的订单量、销售额、客单价等指标，以便优化门店运营策略。
2. 广告投放效果：评估广告点击成本与收益，调整广告投放策略。
3. 顾客消费行为：分析顾客下单时间、订单金额等，了解顾客消费习惯。
4. 地域市场分析：研究各地区的订单量、销售额等，发掘市场潜力。

请您充分利用这个数据集，进行深入分析，为外卖门店运营提供有力支持。
